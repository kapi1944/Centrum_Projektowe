# Realizacja etapu

Pracuj według [AGENTS.md](../../../AGENTS.md). Ustal identyfikator etapu, polecenie stanowiące upoważnienie, bazę Git oraz kryteria odbioru. Przeczytaj dokument etapu i tylko zależne dokumenty wskazujące aktualne kontrakty. Przy niejasnej granicy wykonuj niezależną część zadania, a pytanie ogranicz do brakującej decyzji.

Sprawdź istniejącą implementację i różnice przed edycją. Przenieś do kodu wyłącznie zakres bieżącego zlecenia. Opis A1–A9 ani dostępna umiejętność nie uruchamiają samodzielnie kolejnego etapu.

Zastosuj [procedurę kontroli i raportu](../../../docs/automatyzacja/PROCEDURY.md). Zestaw wynik z kryteriami odbioru: rozdziel wykonane, niewykonane i zablokowane elementy. Jeżeli wykryty błąd wymaga zmiany poza zakresem, zachowaj dowód i wskaż potrzebną decyzję zamiast rozszerzać implementację.
